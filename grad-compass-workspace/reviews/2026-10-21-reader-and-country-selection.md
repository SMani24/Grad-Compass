# Reader composition and bulk research selection

The Belgium overview and detailed report now use aligned section containers and a bounded wider table area. Comfortable/Wide changes the composition coherently. The locator has a responsive overview column/row. The first screen contains useful research instead of repeated administrative facts: a compact title/date/intake/review header, modest credited photo and Report details disclosure.

The toolbar groups reading modes, sections, annotations, Export and Reading options. Text selection reveals Highlight/Comment; source references remain clickable. Sticky navigation accounts for the toolbar's actual height. Existing canonical/editorial version bindings, review dispositions, exact-passage annotations and reading positions are preserved. PDF/Markdown generation and producer formats are unchanged.

Explore countries provides research checkboxes for saved and unsaved entries, Select all matching, a count of selections outside the current filter, and Clear selection. It operates on all 255 catalogue countries/territories, including offscreen or unrendered matches. Individual exclusions and selections survive filter changes and restart, isolated by local profile. Selecting entries does not save countries, change decisions/focus or start research.

Research selected opens the existing composer with the exact complete scope. A 255-entry draft is retained and displayed; the unchanged handoff's 20-country/assigned-code limits are explained before submission. Unsupported scopes cannot be silently truncated into a smaller request. Broad research is not executed by this increment.
