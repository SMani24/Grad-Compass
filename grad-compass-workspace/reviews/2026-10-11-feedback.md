# Feedback fixes — 2026-10-11

Requested items are implemented sequentially and removed from `features_and_bugs.md` after verification. Original feedback remains available in Git history. The synthetic preview remains separate from production data and Research Engine artifacts.

## Country selection

The selected country now has a distinct fill and border along its geometry. Keyboard focus follows the shape rather than showing a rectangular outline around distant islands. Country selection from the map or dropdown frames the dominant landmass; the whole country's geometry remains highlighted.

Verification: seven discovery regression cases passed, including actual France geometry, a dateline-crossing ring and missing geometry. The native Qt smoke check verified selected France's highlight, absence of a rectangular focus outline, and an empty results list when no sample universities match. Existing map, list, details and input focus checks passed.

## Navigation and desktop shortcuts

Browser history now preserves the selected country, search, stage, view and university together. Back/forward controls, Alt+arrows and desktop mouse side buttons use that history. Consecutive search keystrokes share one history stop; changing direction after going back discards the old forward branch. Escape closes university details, clears the country/filter level, then returns a list view to the map. Ctrl+W uses the native close confirmation; Escape/cancellation inside a modal is handled by the modal itself.

Verification: real-browser checks passed for cross-country university restoration, back/forward, Escape levels, grouped search and forward-branch replacement. Three additional Qt input regressions passed for mouse side buttons, Alt+arrows/Ctrl+W and isolation from other windows/open dialogs. The automated preview skips its close confirmation so it can exit unattended.

A separate native close-dialog integration check verified Ctrl+W → No leaves the app and its local server available, and Yes closes the app. The reproducible check is `grad-compass/tests/check_close_confirmation.py`.

## Full-window map

The map now fills the viewport. A compact floating brand/history bar, results panel and view toggle sit over it, with the university inspector opening as a separate floating panel. The large page header and framed central map have been removed. The mobile map uses a bottom results sheet; the mobile list places filters above a full-height comparison panel. Country selection remains highlighted along its outline, with a single keyboard stop for the selected shape and a country dropdown for keyboard exploration.

Verification: 24 Python regression cases, 13 JavaScript cases and three Qt input cases passed. The native smoke check confirmed the map exactly matches viewport width/height and rechecked selection and navigation. Chrome review covered desktop map, list/inspector, France without results, and mobile map/list. Screenshots are local ignored files named `2026-10-11-{map,list,france,mobile,mobile-list}.local.png` in this directory.

All 145 protected tracked production/cache/research/exchange files match the starting commit `aa6f743`. No production database/configuration or profile/CV artifact was changed. All three requested entries are removed from the feedback queue after passing their checks. Further visual feedback can be added there; this implementation does not imply final design approval.
