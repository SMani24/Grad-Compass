# Review checkpoints

Each product-facing increment gets a dated review note with what changed, how to preview it, tested states, limitations, and feedback needed. Include map and list states, missing coordinates/data, loading/error states, keyboard behavior, and larger text where relevant.

All fixtures and screenshots use invented data. Local personal feedback or unpublished screenshots may use `.local.md`/`.local.png` filenames, which are ignored here. Never capture applicant/profile/email contents in a tracked review.

The current checkpoint is [the map-first workspace](2026-10-09-map-workspace.md). Open Grad Compass from the Pop!_OS application menu to review it before further product features are layered on.
