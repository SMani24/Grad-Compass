# Assets

Keep asset briefs, provenance, licensing, and future visual references here. Production assets used by the interface live in `grad-compass/ui/`; reference them from these notes instead of duplicating them.

The first design reuses the bundled Leaflet map, GeoJSON, and existing palette. Add bitmap artwork only when it helps a specific approved experience. Screenshots use synthetic data and belong in `../reviews/`. Personal CVs/photos/documents are private runtime artifacts, not design assets.
## Current interface assets

The desktop compass icon is a small repository-native SVG at `../../grad-compass/ui/assets/grad-compass.svg`. The interface reuses the application's bundled Leaflet files and country geometry. No raster generation or remote asset service is needed for this checkpoint.
