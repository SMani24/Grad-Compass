# Independent country report review

Apply this checklist to ordinary country requests under [the execution contract](ordinary-country-reports.md). Review exact received packages, not candidate filenames or an earlier finding disposition.

1. Verify saved request and reference bytes, approved frozen profile digest/receipt/completion marker, private brief digest, received result/finding identity, both edition revisions/hashes, evidence-map hash and package metadata digest. Keep applicant bindings and comparison notes private.
2. Record **factual support**, **useful request coverage**, and **readability/edition consistency** separately for each detailed and reader edition. Use `pass`, `changes_required`, or `unable_to_review`; explain concrete evidence, omissions, corrections and limits. A populated schema or passing publisher check is not a quality verdict.
3. Check primary-source amounts, coverage, academic year, deadlines, eligibility, degree-completion versus certificate timing, payment/renewal, tuition treatment, residence conditions and arithmetic. A permit minimum is not a full budget. Check that every material source attribution has a legitimate received finding/map binding; mark retrieval failures and historical facts precisely.
4. Compare the saved brief with substantive opportunities, obstacles, national/regional funding, academic routes and practical next actions. Keep eligibility and affordability conditional where inputs are unknown. Do not infer preferences or penalize a country screen for not performing unauthorized programme discovery.
5. Read both editions independently. Keep decisive conditions near claims, reconcile figures and dates, remove duplicate public source inventories, and place app/binding/review operations in Report context. Useful observation dates and evidence-precision qualifications remain accessible.
6. Compare current map and metadata coverage with the actual editions. Flag stale “not investigated,” “no call,” “draft/unreceived,” and supported-current labels attached to historical evidence. These are review defects even when structural validation passes. New map/text bytes require new immutable revisions and compatible reader/map bindings.
7. Record current factual dispositions in exact-bound canonical and reader package metadata with review ID, reviewer, UTC time and scope. Use the existing supported package state `needs_correction` for a `changes_required` factual disposition. Preserve prior metadata bytes as private history before an authorized mutable review update; never rewrite immutable narrative/map files or a finalized received delivery. Preserve human approval independently.
8. Read back metadata and rerun publisher `--check`; record its result separately from the verdict. Give Discovery a bounded correction list and Marry exact edition/hash identities, metadata readback and release limitations. Publication and human approval are separate actions. Return new editions for independent review before release.

A private review index should use a descriptive filename and link to exact machine identities in its structured review record. Public task records contain sanitized dispositions and opaque edition identities only.
